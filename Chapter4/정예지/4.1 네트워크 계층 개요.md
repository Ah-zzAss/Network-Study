## 4.1 네트워크 계층 개요

## 라우터
라우터는 패킷을 처리할 때 1-3계층인 (물리, 링크, 네트워크 계층)을 지나간다.

## 네트워크 계층의 중요한 기능

1. **포워딩 (전달)**  
현재의 router가 packet을 어느 출력 인터페이스로 보내는 과정이다.
하나의 라우터 내부에서 수행되는 동작이다.

2. **라우팅**  
출발지에서 목적지 호스트로의 패킷이 이동할 전체 경로 계산하는 과정이다.

- 라우팅 알고리즘 or 라우팅 프로토콜을 통해 경로를 계산하고, 그 결과를 포워딩 테이블에 반영한다.

3. **포워딩 테이블**  
라우터가 패킷을 어느 출력 인터페이스로 전달할지 판단하기 위해 사용하는 테이블이다.

- 라우터는 패킷 헤더의 필드값을 조사하고, 해당 값을 포워길 테이블의 검색 기준으로 사용한다.
- 일반적인 IP 네트워크에서는 다음과 같이 동작한다. 
    1. 패킷의 목적지 IP 주소 확인
    2. 포워딩 테이블 검색
    3. 출력 인터페이스 결정
    4. 패킷 전달

## 데이터 평면과 제어 평면

1. **데이터 평면**  
각 라우터에서 패킷을 실제로 전달하는 영역이다.
포워딩 테이블을 조회하여 패킷을 출력 인터페이스로 보낸다.

2. **제어 평면**  
패킷이 어떤 경로로 이동해야하는지 계산,  
데이터 평면에서 사용할 포워딩 테이블의 내용을 결정한다.

## 제어 평면의 구현 방식

1. **전통적인 라우팅 방식**

- 각각의 모든 라우터에서 라우팅 기능을 수행한다.
- 라우터들은 라우팅 프로토콜(OSPF, BGF)을 통해 라우팅 메세지를 교환하며 포워드 테이블의 값을 계산한다.

2. **SDN 방식**

- 원격 SDN 컨트롤러가 라우팅 테이블을 계산 및 배분하고, 라우팅 기기는 포워딩만 진행한다.
- SDN에서 네트워크 제어 기능은 소프트웨어로 구현된다.
- 원격 컨트롤러는 높은 신뢰/중복성을 갖춘 원격 데이터 센터에 설치되거나 ISP 혹은 다른 제3자에 의해 관리될 수 있다.

## 네트워크 서비스 모델

네트워크 계층에서 설계에 따라 제공할 수 있는 서비스들은 다음과 같다.

1. 도착이 보장된 전달
2. 지연 시간 이내 보장된 전달
3. 순서화 패킷 전달
4. 최소 대역폭 전달
5. 보안 서비스

> -  인터넷 IP 네트워크는 기본적으로 이러한 보장을 제공하지 않는 Best Effort Service (최선형 서비스)를 사용한다.
> - 관리되는 전용 네트워크에서는 설계에 따라 위의 서비스를 일부 보장을 제공할 수 있다.
