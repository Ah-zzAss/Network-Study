## 4.1 네트워크 계층 개요

네트워크 계층은 트랜스포트 계층으로부터 세그먼트를 얻어 데이터그램으로 캡슐화하고 중계 라우터를 거쳐서 목적지 호스트까지 전달한다.

각 라우터에 데이터 평면과 제어 평면이 존재한다.

- 데이터 평면: 입력 링크에서 출력링크로 데이터그램을 전달
- 제어 평면: 데이터그램이 출발지 호스트에서 목적지 호스트까지 전달되도록 로컬, 라우터별 포워딩

### 포워딩과 라우팅: 데이터 평면과 제어 평면

네트워크 계층의 근본전인 역할은 송신 호스트에서 수신 호스트로 패킷을 전달하는 것이다.

이를 위한 중요한 기능 두 가지는 포워딩과 라우팅이다.

- 포워딩: 패킷이 라우터에 입력 링크에 도달했을 때 적절한 출력 링크로 이동시키는 것
- 라우팅: 송신자가 수신자에게 패킷을 전송할 때 패킷 경로를 결정하는 것

네트워크 라우터에서 필수적인 요소는 포워딩 테이블이다. 도착하는 패킷의 헤더값을 검사하여 포워딩 테이블에 맞게 출력 링크를 결정한다.

#### 제어 평면: 전통적인 접근 방법

라우팅 알고리즘은 라우터의 포워딩 테이블의 내용을 결정한다.

한 라우터의 라우팅 알고리즘 기능은 다른 라우터의 라우팅 알고리즘과 소통하며 포워딩 테이블 값을 계산한다.

#### 제어 평면: SDN 접근 방법

SDN은 원격 컨트롤러가 포워딩 테이블을 계산 및 배분하는 동안 라우팅 기기는 포워딩만을 수행한다.

원격 컨트롤러와 라우터는 포워딩 테이블과 메시지를 교환하며 소통한다.

### 네트워크 서비스 모델

네트워크 계층에서 제공할 수 있는 서비스들은 다음과 같다. 

- 보장된 전달: 패킷이 출발지부터 목적지까지 도착하는 것을 보장
- 지연 제한 이내의 보장된 전달: 패킷의 전달을 보장하고 특정 지연 제한 안에 전달
- 순서화 패킷 전달: 패킷이 목적지에 송신된 순서대로 도착하는 것을 보장
- 최소 대역폭 보장: 송신과 수신 호스트 사이에 최소한의 대역폭을 보장
- 보안 서비스: 모든 데이터그램을 출발지에서 암호화, 목적지에서 해독 할 수 있게 기밀성을 유지
