# 3.2 다중화와 역다중화

- 다중화와 역다중화는 모든 컴퓨터 네트워크에서 필요하다.

### 트랜스포트 계층이 데이터를 전달하는 방법

1. 역다중화: 트랜스포트 계층 세그먼트의 데이터를 올바른 소켓으로 보내는 작업
    - 각각의 트랜스포트 계층 세그먼트는 역다중화를 위해 세그먼트에 필드 집합을 가진다.
    - 수신측 트랜스포트 계층은 수신 소켓을 식별하기 위해 이러한 필드를 검사한다.
    - 이 세그먼트를 해당 소켓으로 보낸다.

2. 다중화: 출발지 호스트에서 소켓으로부터 데이터를 모으고, 이에 대한 세그먼트를 생성하기 위해 각 데이터에 헤더 정보로 캡슐화 하고, 그 세그먼트들을 네트워크 계층으로 전달하는 작업
    - 헤더 정보는 나중에 역다중화에 사용된다.

> #### 소켓이란
    - 네트워크 계층에서, 애플리케이션의 한 부분으로서 프로세스가 소켓을 가진다.
    - 이 소켓은 한 프로세스로부터 네트워크로 데이터를 전달하는 출입구 역할을 한다.
    - 호스트의 트랜스포트 계층은 중간 매개자인 소켓에게 데이터를 전달한다.
    - 수신측 프로세스에 하나 이상의 소켓이 존재할 수 있으므로, 각각의 소켓은 하나의 유일한 식별자를 가진다. (포멧은 UDP, TCP에 따라 다르다)

### 실제로 호스트에서 다중화와 역다중화가 수행되는 방법

트랜스포트 계층 다중화는 2가지의 요구사항을 가진다.
1. 소켓은 유일한 식별자를 가진다.
2. 각 세그먼트는 세그먼트가 전달될 적절한 소켓을 가리키는 특별한 필드를 가진다.
    - 특별한 필드: 출발지 포트 번호 필드, 목적지 포트 번호 필드
    - TCP는 그 외에 추가로 필드를 더 가진다.

> - 출발지 포트번호 사용 목적: 수신 호스트에서 송신 측으로 다시 데이터를 보내기 원할 때, 목적지 포트번호로 해당 출발지 포트번호를 사용한다.

### 비연결형 다중화와 역다중화 (UDP의 기본 동작 방식)

UPD 소켓은 목적지 IP 주소와 목적지 포트번호의 두 요소로 된 집합에 의해 식별된다.

호스트 A의 프로세스 (UDP 소켓 : 포트번호 19157)
-(데이터)-> 호스트 A의 프로세스 (UDP 소켓 : 포트번호 48428)

1. 호스트 A의 트랜스포트 계층: 트랜스포트 계층 세그먼트 생성 
    - 세그먼트 구성: 애플리케이션 데이터 + 출발지 포트번호 (19157) + 목적지 포트번호(48428) + 다른 2개의 값
2. 호스트 A의 트랜스포트 계층: 만들어진 세그먼트를 네트워크 계층으로 전달
3. 호스트 A의 네트워크 계층: 세그먼트를 IP데이터그램으로 캡슐화
4. 호스트 A의 네트워크 계층: IP데이터그램을 최선형 전달 서비스로 수신 호스트 B로 전달
5. 수신 호스트 B: 세그먼트 안의 목적지 포트번호(48428) 검사하여 세그먼트를 적절한 소켓으로 보낸다 (역다중화)

### 연결지향형 다중화와 역다중화 (TCP의 기본 동작 방식)

TCP 소켓은 목적지 IP 주소와 목적지 포트번호, 출발지 IP 주소와 출발지 포트번호로 식별된다.

1. TCP 서버 애플리케이션은 호나영 소켓을 갖고 있으며,  
    포트번호 12000번을 가진 TCP 클라이언트로부터 연결 설정 요청을 기다린다.
2. TCP 클라이언트는 소켓을 생성하고, 연결 설정 요청 세그먼트를 보낸다.
3. 서버 프로세스로 동작하는 컴퓨터의 호스트 OS가 목적지 포스트 12000을 포함하는 연결 요청 세그먼트를 수신하면,  
이 세그먼트를 포트 번호 12000로 연결 수락을 기다리는 서버 프로세스로 보낸다.
4. 서버는 연결 요청 세그먼트 4가지 요소가 일치하면 세그먼트는 해당 소켓으로 역다중화 될 것이다.

### 웹서버와 TCP

연결 소켓과 프로세스 사이에 항상 일대일 대응이 이루어지는 것은 아니다.
오늘날의 많은 고성능 웹서버는 하나의 프로세스만 사용한다.
그리고 각각의 클라이언트 연결을 위해 새로운 연결 소켓과 함께 새로운 스레드를 생성한다.

- 지속적인 HTTP 사용 시: 클라이언트-서버는 같은 서버 소켓을 통해 HTTP 메세지 교환
- 비지속적인 HTTP 사용 시: 클라이언트-서버는 모든 요청/응답마다 새로운 TCP 연결 생성/종료
