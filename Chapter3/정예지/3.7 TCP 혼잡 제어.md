# 3.7 TCP 혼잡 제어

네트워크 혼잡도에 따라 연결에 트래픽을 보내는 전송률을 각 송신자가 제한하도록 하는 것

- TCP 송신자가 자신과 목적지 간의 경로에서 혼잡이 없음을 감자하면 송신자는 송신률을 높임

1. 송신자는 자신의 연결에 송신자 전송 트래픽 전송률을 어떻게 제한

송신자, 수신자는 초반 연결 때 몇가지 변수, 수신/송신 버퍼로 구성되었다.

추가적인 변수인 혼잡 윈도를 추적
혼잡윈도는 TCP 송신자가 네트워크로 트래픽을 전송할 수 있는 속도에 제약을 가한다.

매 RTT 시작할 때 송신자는 혼잡 윈도의 바이트만큼 데이터를 전송 가능, 
RTT 끝나는 시점에 대한 데이터에 대한 확인 응답 수신 -> 송신자의 송신 속도는 cwnd/RTT 바이트/초이다. 

cwnd값을 조절하여 제한 가능

2. 송신자는 자신과 목적지 사이 경로의 혼잡을 어떻게 감지?

타임아웃/ 수신자로부터 중복된 3개의 ACK 수신이 발생했을 때, TCP 송신자 측에 손실 이벤트가 발생했다고 정의.

과도한 혼잡 -> 데이터 그램이 버려지고 -> 송신 측에서 손실이벤트-> 송신자는 혼잡이 발생하였음을 알게된다.
